## Things to know before touching it

- Local tests need PostgreSQL and the CI environment variables; the thread tests skip elsewhere.
- `consistent_read()` runs on PostgreSQL only, so a standalone payout GET under the SQLite settings
  (`local_preview`, `test_local`) fails with `FinanceSnapshotUnavailable`. CI's one SQLite job runs only
  the deployment-safety tests, which pass; the server and the test shards use PostgreSQL.
- Open for Ismail (also in the phase document): EUR choosable with Connect off while a country is
  listed; keeping EUR needs an open country; with the rail closed during a creation, EUR cannot be
  switched off until it reopens; a replay at the 23-hour boundary racing a search could open a second
  account (not built for).
