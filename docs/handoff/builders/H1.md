## 3. How

1. For each candidate: search the repository for its path and its name (workflows, scripts,
   documents, `CLAUDE.md`, `AGENTS.md`, `HANDOFF.md`). A file that a live file names stays, or
   the reference is corrected in the same commit when the file is plainly dead.
2. Put the list in the pull request: the file, the evidence, "removed" or "kept, because".
3. A file you are unsure about stays, with a line in the list. Git keeps everything you remove.
4. **Branches.** List every remote branch: its last commit date, whether it is merged into
   `main`, whether a pull request is open on it, and your proposal (delete or keep). `main` and
   `main-old` stay. `claude/staff-2fa-qr-fix` and `claude/web-domain-wassla-eu` have work that
   may not be on `main`: say exactly what each holds. Give the list to the lead. **Ismail approves
   it before anyone deletes a branch.**

## 4. What is not yours

Any file under `backend/monolith`, `backend/services/cmd`, `internal` or `pkg`, `mobile/lib`,
`infra` or `.github`. `HANDOFF.md` and the board (the lead writes them). This plan and its briefs:
the lead removes them when the last package has merged.

## 5. Done when

1. The pull request has the file list with its evidence, and the branch list.
2. No document on `main` points to a file that does not exist: a link check over `*.md` shows it.
3. Every CI check is green.
