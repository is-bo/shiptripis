Stripe and Chargily both bounce the browser back through a URL the payer's own machine follows, and the only thing that moves money in this system is a signature-verified webhook. A page that read the query string and announced "Payment successful" would be announcing something it does not know, on the one screen where being wrong is most expensive. It also carries no order, no amount and no party. The reference in the URL is enough to render this page and deliberately not enough to learn anything from it — a payer forwards this link without forwarding a receipt. Thanks — we’re confirming your payment

ShipTrip confirms every payment with the payment provider before marking it as received, so this page cannot tell you the outcome yet. It usually takes a few seconds.

You can close this tab. If you paid from the ShipTrip app, go back to it and the delivery will update on its own. If you paid a link someone shared with you, they will see the result on their side.
