{% comment %} The Finance scope, as one GET form. Every control maps to a filter the H5 backend already validates, and the form sends nothing the backend does not accept. The date range is selected, never computed: H5 resolves "last 7 days" in the Europe/Paris reporting timezone and refuses a range longer than 366 days or one ending in the future, which is why no script recalculates a boundary on this page. Ten controls are too many for the flex row the queue screens use, so the selects sit in their own grid and the reference field takes the full width underneath it, next to the actions. That keeps every control the same size and lets the whole bar fall to one column on a phone with no label orphaned from its input. {% endcomment %}
