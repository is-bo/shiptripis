{% extends "admin/base_site.html" %} {% comment %} The manual dinar queue. This is the most human-sensitive workflow ShipTrip has: a person reads an account number off a screen and moves real money by hand, and nothing downstream will catch it if they send the wrong amount to the wrong person. It earns a first-class queue rather than a stage table buried on a dashboard. Four cohorts, in the order one payout travels them. The dinar figure leads on every waiting row because it is the number that gets typed into a bank; the canonical euro sits underneath it because it is the number that is owed. They are never added together and the dinar is never a conversion of the euro at today's rate — it is what was frozen when the instruction was created. {% endcomment %} {% block breadcrumbs %}
