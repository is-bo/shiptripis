The order of this page is the order of the decision, not the order of the model. An operator arrives asking four questions and leaves when all four are answered: *how much do I send*, *where does it go*, *is the Traveler's evidence good*, and *what has already happened to this payout*. Everything on the page belongs to one of those, and anything that belongs to none of them is not on the page. Two things it must never say. It must never suggest ShipTrip performs the bank transfer — a person does, in a banking application, outside this system. And it must never offer a way to declare a payout paid: the only route to `paid` is the backend state machine, through a claim, a committed instruction, a receipt and an explicit settlement attestation, and there is deliberately no control here that skips any of them. {% endcomment %} {% block extrastyle %}{{ block.super }} {% endblock %} {% block breadcrumbs %}
