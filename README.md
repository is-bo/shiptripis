# Wassla

A marketplace where a sender's parcel travels with a traveler who is already making the trip,
aimed at fast delivery. The repository is `shiptripis`.

Start with [`CLAUDE.md`](CLAUDE.md) (the rules for every agent), then [`HANDOFF.md`](HANDOFF.md)
(where the work stands). The product is in [`PRODUCT.md`](PRODUCT.md), the system in
[`ARCHITECTURE.md`](ARCHITECTURE.md), the visual rules in [`DESIGN.md`](DESIGN.md) and the
specifications in [`docs/`](docs/).
